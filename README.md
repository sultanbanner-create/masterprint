## 🌟 Основной функционал

### 1. ⚡ Быстрая касса (POS):
* Сенсорный интерфейс кассира для оперативной продажи услуг.
* **Объединённые мастер-карточки услуг** с моментальным выбором форматов и цен:
  * Ксерокопия & Распечатка (А4 Ч/Б, Цветная, Двухсторонняя, А3, текст)
  * Ламинирование (А4, А3, Визитки/ID)
  * Фото на документы & Фотопечать (3х4, 4х6, Ретушь, 10х15)
  * Переплёт (пружина, твёрдый диплом)
  * Сканирование
* Мульти-корзина с регулировкой количества `[-]` `[кол-во]` `[+]`.
* Поддержка способов оплаты: **Наличные**, **Click / Payme**, **Карыз (Долг)**.
* Мгновенная печать фискального товарного чека с QR-кодом.

### 2. 🧩 Технологические карты & Склад (Автосписание):
* Автоматическое списание сырья со склада при каждой продаже.
* Поддержка **сложных составных услуг (до 3-х ингредиентов одновременно)**:
  * *Фото с рамкой А4 (250г)* автоматически списывает и Рамку А4 со стеклом, и Фотобумагу 250г.
* Аудит и история всех приходов и списаний сырья.

### 3. 📋 CRM Заказов & Наружная реклама:
* Табличный реестр заказов с живым поиском и фильтрами по статусам (`Новые`, `В работе`, `Готовы`, `Выданы`, `Долг`).
* Переключение статуса заказа в 1 клик прямо в таблице.
* Калькулятор широкоформатной печати (баннер 330г/440г, оракал, люверсы, проклейка).

### 4. 💰 Финансы & Кассовые смены:
* Открытие и закрытие кассовых смен (X-отчёт, Z-отчёт).
* Контроль остатка наличных в денежном ящике.
* Учёт расходов цеха и закупок сырья.

### 5. 👥 База клиентов & Учёт долгов (Карыз):
* Карточки клиентов с историей заказов и накопленным долгом.
* 1-клик погашение задолженности в кассу.

### 6. 📊 Месячная выручка & Экспорт в Excel (МАЙ.xlsx):
* Таблица выработки 1–31 по 5 мастерам (Ислам, Бексултан, Азиз, Махмуд, Ажинияз).
* Выгрузка отчёта в Excel.

### 7. 🏆 Фееричный Рейтинг & KPI сотрудников:
* Подиум Топ-3 лидеров месяца (Золото, Серебро, Бронза).
* Bento-карточки выручки, динамики роста и процента качества.

## 🚀 Быстрый запуск

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск сервера
node server.js
```

Система откроется по адресу: **http://localhost:3000**  
В локальной сети: **http://192.168.0.166:3000**
